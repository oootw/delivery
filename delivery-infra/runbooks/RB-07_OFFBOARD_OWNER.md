# RB-07_OFFBOARD_OWNER

Runbook оффбординга владельца без потери данных.

## Шаги

1. Остановить новые раскатки на хост владельца (`pinned_ref` + freeze в CI).
2. Снять финальный бэкап БД и `shared/var`.
3. Экспортировать данные владельцу в согласованном формате.
4. Удалить/архивировать запись сервера в control-plane.
5. Отключить DNS и внешний доступ к серверу.
6. Удалить VM владельца после подтверждения.
7. Сохранить архив бэкапа по юридической политике хранения.
